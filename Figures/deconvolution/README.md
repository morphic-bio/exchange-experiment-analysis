# Main deconvolution figures

This folder contains the core figures generated by the two primary deconvolution notebooks:

- `03_Deconvolution_GCM1.ipynb`
- `03_Deconvolution_ISL1.ipynb`

Run either primary notebook from top to bottom to regenerate its figures. The notebooks use a minimum 16-point base theme; dense heatmap and facet labels that were previously 7–11 points are now 10–14 points. Figures are saved at 300 dpi and are also displayed inline in their source notebooks.

The GCM1 analysis uses single-reference non-negative least squares (NNLS), because its Day-6 single-cell reference contains one independent culture. The ISL1 analyses use `MuSiC::music_prop()` with their available reference sample labels.

## GCM1: single-culture NNLS

Source: `03_Deconvolution_GCM1.ipynb`.

| Figure | How it is generated |
|---|---|
| `GCM1_reference_used_umap_cell_type.png` | UMAP of the exact Day-6 reference cells retained after removing unlabelled and inadequately supported cell types; colored by biological cell type. |
| `GCM1_reference_used_umap_sample.png` | The same retained Day-6 reference cells, colored by culture/sample, showing that the NNLS reference contains one independent culture. |
| `GCM1_deconv_barplot.png` | Stacked per-bulk-sample NNLS proportions. Closely related CTB/early-progenitor and EXM states are relabelled consistently, very small fitted components are removed by the notebook’s global q90 rule, and the principal KO/control groups are shown. |
| `GCM1_deconv_boxplot.png` | Boxplots of the same primary NNLS proportions across the selected perturbation and control conditions. |
| `GCM1_PrimSyn_mean_SEM.png` | Prim.Syn. NNLS proportions for the paper comparison: original bulk-sample values plus the condition mean and SEM. |
| `GCM1_CTB_EXM_scatter.png` | One point per bulk sample comparing fitted CTB-like/early-progenitor and EXM/EXM-progenitor proportions; color denotes perturbation strategy and shape denotes GCM1 KO/control status. |
| `GCM1_reference_overview_umap_cell_type.png` | UMAP of the complete processed GCM1 single-cell reference before the Day-6/support restriction, colored by the original cell-type annotation. |
| `GCM1_reference_overview_umap_day.png` | The complete processed GCM1 reference UMAP colored by differentiation day. |
| `GCM1_reference_overview_umap_sample.png` | The complete processed GCM1 reference UMAP colored by source culture/sample. |

| Figure | How it is generated |

## Notes

- PNG files are the publication-ready exports; notebook outputs remain the record of the executed analysis and include the same generated figures inline.
- Some notebooks also write supporting TSV files to this directory so that the plotted values and summaries remain beside their figures.
- The identity and threshold lines are reference guides. No binned trend or fitted-summary overlay is added to the raw scatterplots.
